## What you need to complete Phase 5
```bash
# Install oss-cad-suite (provides iverilog + vvp + yosys + nextpnr + more)
# Download from https://github.com/YosysHQ/oss-cad-suite-build/releases
# Extract, add its bin/ to PATH.

# Then run each testbench via the MCP:
#   mcp__eda-bridge-mcp__run_simulation with
#     testbench = tb/uart_baud_gen_tb.sv
#     source_files = [rtl/uart_baud_gen.v]
#     vcd_output = sim/uart_baud_gen.vcd

# Or command-line:
cd examples/demo_uart_rx
iverilog -g2012 -o sim/uart_baud_gen.vvp tb/uart_baud_gen_tb.sv rtl/uart_baud_gen.v
vvp sim/uart_baud_gen.vvp
```
