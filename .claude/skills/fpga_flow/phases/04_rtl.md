---

## Phase 4 exit gate (per module)

- [ ] RTL file exists at `rtl/{{module_name}}.v`
- [ ] spec_to_rtl score ≥ 80 (or user explicitly accepts lower)
- [ ] Every self-check FAIL has been repaired or documented as accepted
- [ ] review_rtl reports zero `ERROR`-severity findings
- [ ] Every `WARNING` is either dismissed with rationale or forwarded
      as a Phase 5 coverage point
- [ ] Manual edits (if any) logged
- [ ] User approval: reply **"approve RTL for {{module_name}}"** or tick

Phase 4 overall is complete when **every** module has an approved
review log. At that point Phase 5 unlocks for each module in parallel.
